# 07 — ELSTER-Hersteller-Zertifikat beantragen (externer Track)

**What to build:** Kein Code — der längste externe Hebel der Roadmap. Das ELSTER-
Hersteller-Zertifikat (M11) wird **sofort** beantragt und läuft parallel zu allem anderen
(viele Monate Behörden-Vorlauf). Bis zum Eingang shippt 1.0 „abgabe-bereit" ohne
Übermittlung (ADR-005/-017: UI verspricht keine Abgabe vor dem Zertifikat; Beta kostenlos).

**Blocked by:** None — can start immediately.

**Status:** owner-assigned (NexusHero) — externer Track, kein Agent-Ticket. **Seit ADR-0050 (2026-10-28) nicht mehr auf dem 1.0-Pfad:** 1.0 gibt auf Papier ab; die Übermittlung wird ein 1.x-Ticket, sobald das Zertifikat vorliegt.

- [ ] Antrag auf Hersteller-Zertifizierung gestellt (ELSTER-Entwicklerprogramm/ERiC)
- [ ] Anforderungen der Finanzverwaltung an Hosting/DSGVO/Datenschutz-Folgeabschätzung
      dokumentiert (speist Phase 3s DSGVO-Audit)
- [ ] Status im Roadmap-Dokument (Track-Tabelle) gepflegt; Verzögerungen werden dort
      sichtbar, nicht stillschweigend hingenommen
- [ ] Nach Eingang: Ticket „ELSTER-Übermittlung aktivieren" öffnen (Teil von Phase 3)

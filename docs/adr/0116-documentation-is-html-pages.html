Architecture as of 2026-11-22

Decision · ADR-0116

The documentation is HTML pages in the app's design Accepted

  • Context
  • Decision
  • Consequences
  • Alternatives considered
  • Proof (ADR-0021)
  • Status: Accepted
  • Date: 2026-11-28
  • Deciders: NexusHero (Product Owner)
  • Applies to: docs/, scripts/checks/adr-check.mjs, scripts/checks/register-check.mjs, scripts/checks/lib/html-doc.mjs
  • Builds on: ADR-0021 (a control is proven by breaking it), ADR-0025 (the requirements register is checked against the repository)

#Context

The documentation was 156 Markdown files under docs/. On 2026-11-28 a generator laid them out as a static site in the app's design (docs/site/, pull request #611), with the Markdown as the one source and a check in CI that the pages matched it. That left two forms of every document in the repository: the Markdown that was edited and the page that was read.

The Product Owner decided that the pages replace the Markdown: there is one documentation, and it looks like the app.

#Decision

  1. The HTML pages under docs/ are the documentation and its source. The Markdown files, the generator (scripts/docs/build-site.mjs), its template and its CI check are removed. A page is edited by hand.
  2. Where a page lives. A document keeps the path it had, with .html in place of .md: docs/adr/0012-….html, docs/requirements/register.html. The architecture document is docs/index.html and one page per arc42 chapter (docs/01-introduction-and-goals.html to docs/12-glossary.html); the backend modules are docs/subsystems.html. docs/documents.html lists every document that is neither architecture nor decision.
  3. One stylesheet. docs/assets/site.css carries the look. Its first block is a copy of the app's tokens (packages/tokens/dist/tokens.css) with the dark theme bound to the reader's system setting; when the tokens change, that block is copied again.
  4. A new ADR is a copy of the newest ADR page with its number, title, status and text replaced; it gets a row in docs/adr/index.html and the "Next" step of the ADR before it. A new document of another kind gets a card in docs/documents.html.
  5. The checks read the pages. adr-check and register-check were written for Markdown tables and backtick citations. scripts/checks/lib/html-doc.mjs turns a page back into that shape, one line per line of the HTML file, so the parsers and their tests stay as they are and a finding names the line to open in the page's source.
  6. Diagrams stay PlantUML with the shared style docs/diagram-style.puml, rendered light and dark by scripts/docs/render-diagrams.sh.
  7. README.md files stay Markdown (the repository's own, and those of packages and tools): GitHub shows them where they lie.

#Consequences

  • GitHub shows a page as source code. The documentation is read from a checkout (docs/index.html in a browser) until it is published somewhere; publishing is not part of this decision.
  • The navigation is repeated in every page. A change to it (a new chapter, a renamed entry) is made in all of them. The arc42 chapters and the three library entries are stable; a new ADR or document does not touch the navigation.
  • A change in review is a change of HTML. A diff shows tags beside the text.
  • Pull requests that were open on 2026-11-28 and change a Markdown file under docs/ conflict with this one. Their documentation changes are carried into the pages by hand, or this conversion is repeated after they are merged.
  • Four links were dead in the Markdown and are dead in the pages: use-cases.html to adr/0005-deterministic-core-llm-assist.md, adr/0008-keine-erfundenen-daten.md and adr/0016-dsgvo-loeschung-und-export-im-kern.md, and ADR-0107 to 0051-receipt-scan-pipeline.md. The ADRs with these numbers are about something else, so the intended target is not known.

#Alternatives considered

  • Markdown as the source, the site generated from it (the state of pull request #611). Text stays easy to edit and to review, the navigation exists once, and GitHub renders the documents. Rejected by the Product Owner: two forms of one documentation.
  • Markdown and site side by side, the site as an extra. Rejected for the same reason.

#Proof (ADR-0021)

  • Before the Markdown was removed, the register was read both ways and compared: both tables with the same headers, 15 and 33 rows, every cell equal except one link that now ends in .html; 331 citations in the Markdown, 330 found in the page, the missing one a document path that had become .html and is recognised since html is a cited extension.
  • With the row of ADR-0115 taken out of docs/adr/index.html, adr-check reported ADR-0115 (0115-owl-voice.html) has no row in docs/adr/index.html.
  • With a cited test renamed in docs/requirements/register.html, register-check reported register.html:61 cites apps/api/test/guest-session-gone.test.ts — no such file.
  • Both pages were restored and both checks pass.
